# SecureRetail AI 🛡️📈

An AI-powered smart dashboard designed for small retailers to optimize inventory and enhance cybersecurity.

## 🚀 Features
- **Demand Forecasting:** Predicts future product demand using time-series analysis to prevent stockouts.
- **Inventory Surplus Algorithm:** Calculates exact surplus quantities for liquidation or exchange.
- **Security Scanner:** An AI-powered phishing detection tool to protect against SMS and email scams.
- **Data Management:** Interactive interface to upload custom sales and inventory datasets.
- **Premium UI:** A modern glassmorphism-styled dashboard built with Streamlit.

## 🛠️ Tech Stack
- **Frontend:** Streamlit
- **Machine Learning:** Scikit-learn, Prophet, Pandas, NumPy
- **Visualizations:** Plotly
- **Language:** Python 3.11+

## 📂 Project Structure
- `app.py`: Main Streamlit application.
- `src/`: Core logic modules for forecasting, inventory, and security.
- `data/`: Sample datasets for demonstration.
- `models/`: Pre-trained phishing detection models.

## 🚦 Getting Started
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   streamlit run app.py
   ```
